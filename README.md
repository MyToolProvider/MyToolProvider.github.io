# MyToolProvider — Static Functional Edition

This version is designed for GitHub Pages and keeps the toolset browser-first. GitHub Pages publishes static HTML, CSS and JavaScript files; it does not run server-side languages.

## Removed
- Optional AI backend
- Server/API-dependent AI generation button
- Backend configuration and API-key files

## Kept
All tools that can run locally in the browser, including calculators, text utilities, developer utilities, local file/image processing, trackers, planners, checklists, decision helpers, travel planning utilities, and local prompt builders.

AI Productivity tools now generate structured prompts locally; they do not claim to call an AI API.

Site URL: https://mytoolprovider.github.io/
