# AllInOne — Connected Utility Hub

A dark-first, responsive static website concept with 13 connected categories and 100+ tool destinations.

## Deploy
Upload the contents to a GitHub Pages repository. Before launch, replace `mytoolprovider/mytoolprovider` in `robots.txt` and `sitemap.xml`.

## Important
The current build is the **experience/architecture layer**: category pages and tool workspaces are connected, responsive, searchable and theme-aware. Individual tools can be upgraded one by one into fully functional browser utilities without changing the navigation system.
